小米路由器开启SSH

发表于 2025-11-04 分类于 运维工具

小米路由器开启 SSH 方法指南，使用官方工具或 Xmirpatcher 均可实现。

方法一：使用官方 SSH 工具包

步骤一：确认路由器固件版本

  1. 登录路由器 Web 管理界面
  2. 在「常用设置 → 系统状态」中查看当前路由版本
  3. 若为稳定版，需先升级为开发版 ROM 固件

进入小米路由官网，依次选择「下载 → ROM」，下载对应型号的开发版 ROM 固件

  1. 在路由器 Web 管理页面的「手动升级」中上传并升级

步骤二：下载 SSH 工具包

  1. 进入小米路由器官网「开放 → 开启 SSH 工具」页面
  2. 登录小米账号，关联绑定的路由器，记录 root 密码
  3. 下载工具包，将 bin 文件复制到 FAT/FAT32 格式 U 盘根目录
  4. 文件名必须为：miwifi_ssh.bin

步骤三：安装 SSH 工具包

  1. 断开小米路由器电源
  2. 将 U 盘插入 USB 接口
  3. 用卡针按住 reset 按钮，接通电源
  4. 指示灯变为黄色闪烁状态时，松开 reset 键
  5. 等待 3-5 秒安装完成，路由器会自动重启

方法二：使用 Xmirpatcher 工具

步骤一：下载工具

从 GitHub 下载 Xmirpatcher 工具，解压后打开文件夹，找到 run.bat 文件

步骤二：运行并解锁 SSH

  1. 双击运行 run.bat
  2. 检查界面显示的 IP 地址是否正确
    • 若不正确，输入 1 手动修改
  3. 输入 2 开始解锁 SSH
  4. 按提示输入路由器后台密码
  5. 等待提示解锁成功

SSH 登录信息

  • 用户名：root
  • 密码：工具中获取的密码
  • 端口：22

注意事项

  • 开启 SSH 后，可使用 Putty、Xshell 等工具连接
  • 开启 SSH 可能使路由器失去保修
  • 操作不当可能导致路由器故障，请谨慎操作
