Docker 部署 FileBrowser 文件管理器

发表于 2022-02-18 分类于 Docker

FileBrowser 是一个基于 Web 的文件管理器，可以用来搭建私有网盘。

1. 创建目录

2. 启动 Docker 容器

参数说明

参数 说明
-v /:/srv/ 映射根目录到容器
-v .../filebrowser.db:/database.db 持久化配置数据库
--user $(id -u):$(id -g) 使用当前用户运行
-p 8088:80 映射端口
--restart=always 开机自启

3. 访问

浏览器打开 http://你的IP:8088 即可访问。

默认用户名：admin
默认密码：admin
